Setup

one command installs everything · five accounts to link

Install
curl -fsSL https://raw.githubusercontent.com/skw-fuj/crea/main/install.sh | bash

Plug the Mac Mini in, open Terminal, paste that, walk away for twenty minutes. It installs the runtimes, the speech models, the voice, the scheduler and CREA itself, then walks you through the accounts one at a time.
